# Customer Churn Prediction 📉

A beginner-friendly machine learning project that predicts telecom customer churn using Logistic Regression, Random Forest, and XGBoost. Includes exploratory data analysis (EDA), preprocessing, evaluation, ROC curves, confusion matrix, and feature importance.

## Dataset

Use the [IBM Telco Customer Churn dataset on Kaggle]

## Methods

- EDA: churn distribution and churn rates by contract, services, and payment method
- Preprocessing: missing-value imputation, one-hot encoding, and numerical scaling
- Models: Logistic Regression, Random Forest, and XGBoost
- Metrics: accuracy, precision, recall, and ROC-AUC
- Interpretation: confusion matrix, ROC curves, and tree-based feature importance
